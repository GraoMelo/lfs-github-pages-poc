LFS Configuration Test Repository

⚠ Research PoC — This repository demonstrates Git LFS trust boundary bypass (DSM-002-V1).

This GitHub Pages site serves a .lfsconfig file that redirects Git LFS traffic to an external endpoint.

Files served via GitHub Pages CDN

  • .lfsconfig — LFS URL override
  • .gitattributes — LFS tracking rules
  • .gitmodules — Submodule configuration

Impact

Any CI/CD pipeline or developer that downloads and applies this .lfsconfig will have their Git LFS traffic redirected — including credentials sent via Basic auth headers.
